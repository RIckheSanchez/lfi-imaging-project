## C. UI behavior

`part4_ui/volume_panel.py:59` adds a collapsed Depth calibration section only for the registered Part 3 adapter after a data load. Its QLineEdit fields start empty; `app.py:426` clears them on every new file/folder attempt. Values are not persisted in QSettings.

`z_start_mm` is the depth at `first_frame_id`; `z_step_mm` is the increment per integer frame ID. The start and step must be positive and finite, the first ID must be an integer actually present in the scan, and all mapped depths must be positive. Alternatively, one finite, unique, nonnegative metadata depth per slice is accepted. At least two slices are required. Incomplete manual input does not silently fall back to metadata. See `adapters/part3.py:10` and `app.py:684`.

The backend linearly interpolates amplitude along calibrated depth and selects phase from the nearest measured slice. No phase-to-depth inference or unit conversion is added.
