## Packaged application / 打包应用

Built `dist/LFI Viewer.app` with PyInstaller, arm64, version 1.3. Cocoa validation uses the real `Realdata/chip_borad1.hdf5` dataset, preprocessing adapter and OpenGL geometry. Capture helper: `packaging/release_smoke.py`. The validation-only export capture uses Qt's save dialog to permit reproducible widget screenshots; normal operation uses the platform-native save dialog. Its title and complete export summary are also recorded in the report.

```
/tmp/lfi-v13-venv/bin/python -m PyInstaller --clean --noconfirm 'LFI Viewer.spec'
LFI_VALIDATE_BUNDLE="$PWD/docs/screenshots/v13" LFI_VALIDATE_FILE="$PWD/Realdata/chip_borad1.hdf5" 'dist/LFI Viewer.app/Contents/MacOS/LFI Viewer'
codesign --verify --deep --strict 'dist/LFI Viewer.app'
```
