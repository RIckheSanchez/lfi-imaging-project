## Numeric migration

Before migration, all three old amplitude, phase and z_indices arrays were saved outside Git in /tmp/lfi-v11-baselines. Exact np.array_equal comparison passed for each array in all three files; see tests/v11-array-equal-output.txt. Committed shape/Z/SHA256 baselines canonicalize numeric arrays to little-endian float64 to permit the intentional raw-phase dtype preservation. No large baseline arrays are committed.

mushroom phase is uint16. Slice normalization, brightness/contrast, histogram calculations and volume processing use float64; CSV exports the original values. Tests cover unsigned counts and exact mushroom CSV readback.

## Fresh environment and bundle

Fresh arm64 Python 3.13 environment: /tmp/lfi-v11-clean. Install runtime, dev and legacy requirements from scratch. QT_QPA_PLATFORM=offscreen is used for pytest-qt. Full outputs are in tests/v11-clean-*.txt.

The packaged app is built from this environment and launched using the Cocoa platform with the real chip file. The opt-in bundle validation script switches 2D to Phase before capturing, and captures both Volume and Isosurface with their actual OpenGL framebuffer. Results and screenshots are in docs/screenshots/bundle-validation/. No OpenGL fallback is used.

Final result: 89 passed, 91 warnings. Legacy CSV, isosurface object, PNG 300 DPI (299.9994 stored), both phase label states, upload reruns/cleanup and cache switching passed. Warnings include intentionally unconfirmed phase encoding and upstream NumPy/skimage deprecations. The app is arm64, approximately 217 MiB on disk, with valid Volume and Isosurface OpenGL contexts and no captured application errors. It is locally ad-hoc signed, not notarized for distribution.
